API 说明

TMDB Key

访问 themoviedb.org/settings/api，注册并登录后创建 API Key，复制后粘贴到「TMDB Key」。

Assrt Token

访问 assrt.net/usercp.php 登录，在用户中心找到 API Token 并粘贴到「Assrt Token」。

OpenSubtitles Key

访问 opensubtitles.com/consumers，注册应用后获取 API Key，粘贴到「OpenSubtitles Key」。

Worker 代理地址

部分在线功能（如搜索、获取详情、图片代理）需要一个代理服务转发请求（如 Cloudflare Worker）。将服务的 HTTPS 地址粘贴到「Worker 代理地址」即可。JavBus 等子功能会自动复用此地址（拼接 /javbus 子路径），无需单独填写。不填则相关在线功能不可用。
