API 说明

TMDB Key

访问 themoviedb.org/settings/api 注册并创建 API Key，复制后粘贴到「TMDB API Key」。

Assrt Token

访问 assrt.net/usercp.php 登录，在用户中心找到 API Token。

OpenSubtitles Key

访问 opensubtitles.com/consumers 注册应用后获取 API Key。

Worker 代理地址

部分在线功能（搜索、详情、图片代理）需要代理服务转发请求，填入 HTTPS 地址即可。JAV 等子功能会自动复用该地址。不填则相关在线功能不可用。
